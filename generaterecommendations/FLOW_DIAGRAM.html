Claude CLI — Why It's Required

1. Deep Strategy Analysis

Used in publish-pick.cjs and analyse-tiles.cjs

Generates 4-section analysis per pick: strategy rationale, technical indicators (RSI, MACD, Bollinger Bands, moving averages), theta decay schedule with daily projections, and risk analysis with management plan.

claude --print -p "Analyze this Iron Condor trade on BABA..."

2. Social Media Copy

Used in generate-social-copy.js

Generates platform-specific captions: LinkedIn (professional, 150-200 words), Twitter (3-tweet thread, 280 chars each), Instagram (engaging caption + 15 hashtags). Each tailored to the platform's tone and audience.

claude --print -p "Generate social media posts for $BABA Iron Condor..."

3. Sentiment Analysis (Claude Engine)

Used in sentiment-engine.cjs (30% weight)

Performs web search for recent financial news, analyst reports, and market commentary. Returns sentiment score (0-100), key drivers with impact assessment, and material events. Uses --allowedTools WebFetch,WebSearch.

claude --print --allowedTools WebFetch,WebSearch -p "Analyze sentiment for BABA..."

Install Claude CLI

Claude CLI requires an Anthropic account. Once installed, authenticate with your API key.

npm install -g @anthropic-ai/claude-code
# or via Homebrew (macOS):
brew install claude

After install, run claude once to authenticate.

Quick Start (Fresh Machine)

# 1. Install Node.js
nvm install 20

# 2. Install Claude CLI
npm install -g @anthropic-ai/claude-code
claude # authenticate

# 3. Install dependencies
cd newleaf-generaterecommendations
npm install

# 4. Configure environment
cp .env.template .env
# Edit .env with your API keys

# 5. Add Firebase credentials
# Download serviceAccountKey.json from Firebase Console
# Place in project root

# 6. (Optional) Install Python for PDF generation
pip install weasyprint pypdf reportlab

# 7. Publish your first pick!
npm run publish -- NVDA --strategy "iron condor" --expiry 2026-06-06 --dry-run
