Pipeline Scheduler

All scheduled jobs in the NewLeaf data pipeline — entry point: pipeline/index.js

Overview

The scheduler is a long-running Node.js process using node-cron. It replaces system crontab and manages all data collection, enrichment, and publishing jobs. It must be running continuously on the local machine.

# Start the scheduler (production)
cd pipeline && npm start

# One-shot mode (run fast pipeline once and exit)
node index.js --once

# Verify it's running
ps aux | grep "node index.js" | grep -v grep

Job Details

1. Fast Pipeline INTRADAY

Script: pipeline-fast.js --watchlist | Concurrency: 5 parallel workers | Runtime: ~2 min

Fetches live prices, IV, and Greeks from Alpaca for all 111 watchlist symbols. Runs the scoring engine (gamma + IV + trend pillars) and uploads per-symbol reports to R2. Does not fetch OI data (that's daily only).

Alpaca API→ Score engine→ reports/{SYM}/latest.json→ R2 upload

2. Daily OI Enrichment DAILY

Scripts: 3-step sequence | Concurrency: 2 (Nasdaq rate limit) | Runtime: ~15-25 min

Fetches Open Interest from Nasdaq (with Yahoo Cloud Function fallback), recalculates gamma walls, regenerates the watchlist manifest, and syncs to Firestore.

Nasdaq OI + Yahoo fallback→ Gamma walls recalc→ R2 upload→ Manifest regen→ Firestore sync

Catch-up: If the 9:32am cron fires but the machine was asleep, the health check (every 5 min) detects the missed run and executes it as soon as the market is open. Uses stamp file .daily-oi-stamp.

3. Daily Funnel DAILY

Script: generaterecommendations/funnel-price.cjs | Runtime: ~5 min

Reads the latest scanner results, ranks symbols by signal strength, prices the top candidates using live Alpaca options data, and publishes to Firestore as trade tiles.

Scanner results→ Rank + filter→ Price top N→ Firestore tiles

4. Weekly Premium Snapshot WEEKLY

Script: generaterecommendations/weekly-premium-snapshot.js | Runtime: ~2 min

Captures a canonical snapshot of ATM call/put premiums (mid price, % of stock, annualized) for all 111 symbols. Used by the Movement & Range page for week-over-week premium comparisons.

Pipeline reports→ Extract premiums→ R2: premium-snapshots/{week}.json→ R2: premium-series/{SYM}.json

Catch-up: If the Friday 4:30pm cron is missed, the health check catches up on Fri/Sat/Sun. Uses stamp file .weekly-snap-stamp.

Manual backfill: node weekly-premium-snapshot.js --week 2026-W22

5. Health Check ALWAYS

Script: built-in + check-scheduler-health.sh | Every 5 min

Monitors system health and catches up missed jobs:

  • Auto-restarts server.cjs if it crashes
  • Catches up daily OI enrichment if missed (market hours only)
  • Catches up weekly premium snapshot if missed (Fri/Sat/Sun)
  • Runs health check script for pipeline freshness and R2 status

Stamp Files

The scheduler uses stamp files to track which jobs have already run, preventing duplicate execution and enabling catch-up:

FileContentsPurpose
.daily-oi-stampDate string, e.g. 2026-06-05Prevents daily OI from running twice on the same day
.weekly-snap-stampISO week, e.g. 2026-W23Prevents weekly snapshot from running twice in the same week
