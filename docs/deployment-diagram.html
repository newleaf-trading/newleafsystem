Caching Strategy

CACHED   Yahoo OI Service

WhatOption chain data (OI, IV, volume per strike)
WhereIn-memory (Python dict) in Cloud Run container
TTL60 minutes
Why 60 minOI updates once daily after market close (~5:30 PM ET). During trading hours, OI is yesterday's number. 60 min is very conservative.
Cold miss~2 seconds (yfinance call to Yahoo Finance)
Cache hit~5 milliseconds
Max entries200 (auto-prune oldest)
InvalidationTTL-based only. Container restart clears cache.

CACHED   Firebase Hosting (CDN)

WhatStatic assets (JS, CSS, images, fonts)
WhereFirebase CDN edge nodes worldwide
TTLJS/CSS: 1 hour | Images/fonts: 1 week | HTML: no-cache
WhyVite builds produce hashed filenames — safe to cache long. HTML always fresh for SPA routing.

CACHED   Cloudflare R2

WhatPipeline reports, PDFs, manifests
WhereCloudflare edge (public bucket with CDN)
TTLCache-Control: 1 hour for JSON, immutable for PDFs
WhyPipeline uploads once daily. Reports are stable.

CACHED   Firestore Client SDK

WhatTiles, analyses, weeklyPicks, user data
WhereBrowser (Firestore SDK auto-caches with offline persistence)
TTLAutomatic (real-time listeners stay fresh; queries cache for offline)

Request Flow with Caching

  User loads AAPL on discover.html:

  1. GET /api/snapshot/AAPL
     └─→ API → Alpaca (real-time)                          NO CACHE    ~500ms

  2. GET /api/indicators/AAPL
     └─→ API → Alpaca 250 bars → shared/indicators/        NO CACHE    ~800ms
         (could be cached 5 min — bars don't change intraday)

  3. GET /api/gamma-analysis/AAPL/2026-06-12
     └─→ API → Yahoo OI Service (Cloud Run)
              └─→ Cache HIT?  → return in ~5ms             CACHED 60m
              └─→ Cache MISS? → yfinance → Yahoo Finance   ~2000ms
                               → cache result
              → API computes BS gamma, walls, confidence    ~50ms

  4. POST /api/ai-read { ticker, spot, rsi, ... }
     └─→ API → LLM Router → QwQ (DashScope)               NO CACHE    ~3000ms

  5. User clicks "Find strategies"
     POST /api/recommend { ticker, expiry }
     └─→ API → LLM Router → Claude Sonnet                  NO CACHE    ~5000ms

  6. User clicks "Verify trade"
     POST /verify { ticker, legs, ... }
     └─→ API → 8-agent pipeline
              → 4 analysts parallel → LLM Router            NO CACHE    ~24s
              → 2 debate agents    → LLM Router                         $0.05
              → risk + judge       → LLM Router
         (could cache by legs hash for 30 min)

  Total for full flow: ~35s, ~$0.07
  With recommended caching: ~25s, ~$0.06
