Setup Steps for api.newleafsystem.com

# 1. In Cloudflare Dashboard → DNS → Add Record:
   Type: CNAME
   Name: api
   Target: us-central1-newleaf-trading.cloudfunctions.net
   Proxy: ON (orange cloud)

# 2. In Cloudflare → SSL/TLS:
   Mode: Full (strict)

# 3. In Cloudflare → Rules → Page Rules (or Transform Rules):
   # Forward /api/* to the Cloud Functions origin
   # The CF proxy handles SSL termination + caching

# 4. In Firebase Console → Hosting → Custom Domain:
   Add api.newleafsystem.com
   Verify ownership via Cloudflare DNS TXT record

# 5. Update frontend configs:
   # web/workbench/discover.html:
   window.__CONFIG__ = { API_URL: "https://api.newleafsystem.com", ... }

   # generaterecommendations/.env:
   NEWLEAF_API_URL=https://api.newleafsystem.com

   # desk/.env or config:
   VITE_API_BASE_URL=https://api.newleafsystem.com

# 6. Optional: Cloudflare Rate Limiting
   Path: /api/*
   Rate: 60 requests/minute per IP
   Path: /verify
   Rate: 5 requests/minute per IP (expensive)

Market Data Endpoints

GET /api/snapshot/:ticker free web/workbench genrecs

Current price, daily bar, latest quote, and available option expirations.

Source: Alpaca Markets API

Consumers: discover.html (Step 1 ticker load), strategy-builder.html, publish-pick.cjs

{ "snapshot": { "price": 308.41, "change": 2.15, ... }, "expirations": ["2026-06-05", ...] }
GET /api/chain/:ticker/:expiry basic web/workbench

Options chain grouped by strike with bid/ask/mid/IV/delta for calls and puts.

Source: Alpaca Markets API

Consumers: discover.html (Step 2 strategy building, Step 3 legs enrichment)

{ "strikes": [{ "strike": 300, "call": { "bid": 12.5, "ask": 13.0, "mid": 12.75, "iv": 0.28, "delta": 0.55 }, "put": {...} }] }
GET /api/indicators/:ticker basic web/workbench genrecs

Computed technical indicators from 250 daily closing prices.

Source: Alpaca bars → shared/indicators/ computation

Consumers: discover.html (Step 1 stat tiles), genrecs/indicators-fetch.cjs (ground truth for LLM prompts)

{ "indicators": { "rsi14": 55.3, "macdLine": 1.234, "macdSignal": 0.987, "macdHistogram": 0.247, "sma20": 195.3, "bollingerUpper": 202.1, "bollingerLower": 188.5, "adx14": 22.5, "atr14": 3.45, ... } }
GET /api/gamma/:ticker/:expiry basic web/workbench

OI-based gamma walls and per-strike open interest breakdown.

Source: Yahoo OI Service (Cloud Run) → Nasdaq fallback

Consumers: discover.html (OI wall card), strategy-builder.html gamma popup

{ "putWallStrike": 275, "callWallStrike": 320, "spotInsideBand": true, "oiByStrike": [...], "walls": [...], "spot": 308.41 }
GET /api/gamma-analysis/:ticker/:expiry basic web/workbench NEW

Full gamma analysis: dual walls (OI + GEX), ATM IV, confidence scores, top gamma strikes. Works for ANY optionable ticker — no R2/pipeline dependency.

Source: Yahoo OI Service (Cloud Run) → computed in api/src/tools/nasdaq-oi.ts

Consumers: discover.html (Step 1: GEX wall card, ATM IV tile, confidence panel, deep-dive gamma chart)

GET /api/sentiment/:ticker basic web/workbench genrecs

4-engine composite sentiment: Claude + Grok + Gemini + Reddit/StockTwits. All LLM engines route through the LLM router.

Source: LLM Router (Claude/Grok/Gemini) + Reddit/StockTwits HTTP

Consumers: genrecs/sentiment-fetch.cjs (publish-pick, analyse-tiles), discover.html (future)

{ "composite": { "score": 72, "label": "bullish", "confidence": 0.85 }, "engines": { "claude": {...}, "grok": {...}, "gemini": {...}, "reddit": {...} }, "cost": {...} }
GET /api/bars/:ticker basic api internal

Historical daily bars (up to 365 days). Used internally by indicators computation.

Source: Alpaca Markets API

AI / LLM Endpoints

POST /api/llm/call basic genrecs

Generic LLM call. Body: { model, system, user, maxTokens }. Routes through LLM router with cost tracking.

Consumers: genrecs/llm-call.cjs (publish-pick, analyse-tiles, process-wip-picks, generate-social-copy)

{ "response": "...", "model": "claude-sonnet", "cost": { "totalCost": 0.028, "totalInputTokens": 1480, "totalOutputTokens": 1575 } }
POST /api/ai-read premium web/workbench

One-sentence AI market read. Body: { ticker, spot, ivRank, rsi, adx, trend, putWall, callWall }.

Consumers: discover.html (Step 1 AI Read callout)

POST /api/recommend premium web/workbench

AI strategy ranking. Returns 3 scored strategies with rationale. Body: { ticker, expiry, modelMode }.

Consumers: discover.html (Step 2 AI mode — ranked strategy cards)

POST /verify premium web/workbench

8-agent verification pipeline (~30s, ~$0.05). Body: { ticker, structure, legs, netCredit, source, modelMode }.

Consumers: discover.html (Step 4 AI Verification Desk → Step 5 Verdict)

{ "verdict": { "call": "pass", "confidence": 72, "rationale": "..." },
  "evidence": { "technical": {...}, "gamma": {...}, "iv": {...}, "sentiment": {...} },
  "debate": { "rounds": [...] }, "suggestedFix": {...},
  "cost": { "totalCost": 0.05, "totalInputTokens": 8500 } }
POST /api/adjust premium web/invest

Position adjustment recommendations for existing trades.

POST /api/event-risk premium web/invest

Event risk analysis for positions (earnings, ex-div, macro).

POST /api/strike-compare basic web/invest

Strike comparison analysis between alternative setups.

Data Flow Diagram

  Browser (discover.html)
    │
    ├─ /api/snapshot/:ticker           → Alpaca (spot, quote, daily bar)
    ├─ /api/indicators/:ticker         → Alpaca bars → shared/indicators/ → RSI, MACD, BB, SMA
    ├─ /api/gamma-analysis/:ticker/:e  → Yahoo OI Service → GEX walls, ATM IV, confidence
    ├─ /api/chain/:ticker/:expiry      → Alpaca (options chain)
    ├─ /api/ai-read                    → LLM Router (qwq) → one-sentence synthesis
    ├─ /api/recommend                  → LLM Router (claude-sonnet) → 3 ranked strategies
    └─ /verify                         → 8-agent pipeline (4 analysts + 2 debate + 2 synthesis)
                                          → LLM Router (deepseek, claude-sonnet, claude-haiku)
                                          → verdict + evidence + debate + mutations

  genrecs (publish-pick.cjs)
    │
    ├─ /api/indicators/:ticker         → ground truth for LLM prompts (F1)
    ├─ /api/sentiment/:ticker          → 4-engine composite (F3)
    └─ /api/llm/call                   → analysis generation (F4)

  Yahoo OI Service (internal)
    │
    └─ https://yahoo-options-svc-...   → yfinance → real OI, IV, volume per strike
       Called ONLY by api/src/tools/nasdaq-oi.ts
       Never called directly by frontend
