1. Monorepo Structure

newleafsystem/
├── web/                          React SPA (Picks, Invest, Workbench)
├── api/                          LLM Router + API endpoints (TypeScript)
├── pipeline/                     Yahoo OI service + cron schedulers
├── generaterecommendations/      Pick generation + tile creation
├── shared/
│   └── indicators/               Pure-math technical indicators (JS)
├── docs/                         Architecture docs
├── ARCHITECTURE.md               Operational guide
└── .gitignore

web/

React + Vite SPA. Three products: Picks site (public), Invest app (authenticated), Workbench (DIY tools). Served from dist/ via server.cjs at localhost:3000.

Build: npm run build (vite) → node server.cjs

api/

TypeScript + Fastify. LLM router, market data tools, sentiment, indicators, verification pipeline. Runs at localhost:5400.

Build: npm run build (tsc) → npm run dev (tsx watch)

pipeline/

Yahoo OI service (Python, localhost:5300), cron schedulers (node-cron), watchlist management. Always-on data layer.

Run: node index.js + cd yahoo-svc && python3 option_api.py

generaterecommendations/

Pick publishing, tile analysis, PDF reports, social content, weekly email. Sole writer to tiles/analyses/weeklyPicks collections.

Run: npm run publish -- SYMBOL --strategy "..." --expiry DATE

4. Data Flow

Pick Publishing Pipeline

publish-pick.cjs
  │
  ├─ 1. Alpaca API        → spot price, option chain
  ├─ 2. R2 CDN            → gamma walls (latest.json)
  ├─ 3. Strike selection   → build strategy legs
  ├─ 4. Write tile         → Firestore tiles/{id} + provenance
  ├─ 5. GET /api/sentiment → 4-engine composite sentiment
  ├─ 6. GET /api/indicators→ RSI, MACD, Bollinger, SMAs (ground truth)
  ├─ 7. POST /api/llm/call → analysis JSON (claude-sonnet default)
  ├─ 8. Validate           → structure + indicator echo-back
  ├─ 9. Write analysis     → Firestore analyses/{id} + provenance
  ├─ 10. Write weeklyPicks → Firestore weeklyPicks/{weekId}
  └─ 11. Save enriched.json→ local output/{week}/enriched/

Technical Indicators Flow

shared/indicators/index.js    (pure math: SMA, EMA, RSI, Bollinger, MACD)
       │
       └─ imported by api/src/tools/indicators.ts
              │
              ├─ adds ADX, ATR, SMA alignment (bar-based)
              └─ exposed via GET /api/indicators/:ticker
                     │
                     └─ consumed by genrecs/indicators-fetch.cjs
                            │
                            └─ injected as GROUND TRUTH into LLM prompts

Sentiment Flow

api/src/tools/sentiment.ts
  │
  ├─ Claude (via router: claude-haiku)  → web search + news
  ├─ Grok   (via router: grok)         → X/Twitter social
  ├─ Gemini (via router: gemini-flash)  → Google News + sector
  └─ Reddit (direct HTTP, no LLM)      → Reddit + StockTwits
  │
  └─ Weighted composite: 30% / 25% / 25% / 20%
         │
         └─ exposed via GET /api/sentiment/:ticker
                │
                └─ consumed by genrecs/sentiment-fetch.cjs
