Migration Plan 5 Phases

Ordered by priority. Each phase is independently shippable — no big-bang migration.

P0 · Critical Remove API Keys from config.json ~1 hour

API keys for Grok and Gemini are hardcoded in scanner/config.json which is tracked by git. Move to environment variables immediately.

  • - Remove apiKey fields from scanner/config.json
  • + Read from process.env.GROK_API_KEY and process.env.GEMINI_API_KEY in scanner/sentiment-engine.js
  • + Add keys to .env (gitignored) and document in .env.example
  • ! Rotate both API keys since they've been exposed in git history
P1 · High Add Gemini to LLM Router ~2 hours

Add gemini-flash and gemini-pro as model tiers in the LLM Router. This unlocks cost tracking for all Gemini calls.

  • + Add 'gemini-flash' | 'gemini-pro' to ModelTier in newleaf-api/src/llm/router.ts
  • + Add @google/generative-ai dependency to newleaf-api/package.json
  • + Implement callGemini() method in LLMRouter class
  • + Add pricing: Flash ($0.15/$0.60), Pro ($1.25/$5.00) per million tokens
  • + Add GEMINI_API_KEY to newleaf-api/.env.local
  • ~ Update newleaf-api/src/tools/sentiment.ts to call Gemini through router instead of direct SDK
P2 · Core Unify Sentiment Engine ~1 day

Merge the 4-engine design from scanner/sentiment-engine.js into newleaf-api/src/tools/sentiment.ts as the single implementation. Add the missing Claude engine. Add caching.

  • + Add Claude sentiment engine to newleaf-api/src/tools/sentiment.ts (calls claude-sonnet via LLM Router with web search prompt)
  • ~ Route Grok + Gemini through LLM Router (not direct SDK)
  • + Add 6-hour Firestore cache (replace file-based cache)
  • + Add computeModifier() and buildSentimentContext() to API
  • + Add Serper web search integration for Claude engine (already have Serper tool)
  • ~ Update pipeline/analyse-tiles.cjs to call GET /api/sentiment/:ticker instead of importing sentiment-engine.js
  • - Delete scanner/sentiment-engine.js (replaced by API)
  • + Test: same ticker produces same score from discover.html and pipeline
P3 · Major Create /api/analyze-tile & Migrate Pipeline ~1-2 days

Replace Claude CLI spawns in the pipeline with a proper API endpoint. This gives cost tracking, version pinning, and fallback capability.

  • + Create newleaf-api/src/routes/ai-tile.ts — POST /api/analyze-tile
  • + Endpoint accepts: { symbol, strategy, legs, greeks, gammaData, sentiment, expiry, dte }
  • + Returns: { strategyRationale, technicalIndicators, thetaDecaySchedule, riskAnalysis }
  • + Primary model: claude-sonnet (pinned at Sonnet 4); Fallback: deepseek-r1
  • + Port the rich prompt template from analyse-tiles.cjs into the endpoint
  • ~ Refactor pipeline/analyse-tiles.cjs: replace spawnSync('claude',...) with fetch('http://localhost:4000/api/analyze-tile',...)
  • - Remove callClaude() function from analyse-tiles.cjs
  • + Test: run analyse on 3 tiles, verify JSON output matches current schema
P4 · Cleanup Migrate Firebase aiChat + Cost Dashboard ~1 day

Route Firebase aiChat through the API. Build a simple cost dashboard that reads from Firestore usage logs.

  • + Create newleaf-api/src/routes/ai-chat.ts — POST /api/portfolio-chat
  • + Accept: { message, portfolio, tiles, settings, history }
  • + Use gemini-flash via router (cost tracked)
  • ~ Update Firebase aiChat function to call API instead of direct Gemini REST
  • + Add cost logging middleware: write each request's llm.getUsage() to Firestore usage/{date}/{requestId}
  • + Create workbench/ai-costs.html — admin page showing: cost per model/day/feature
  • + Add GET /api/admin/costs?from=&to= endpoint for dashboard
