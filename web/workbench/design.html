Scheduler & Service Management

Fully automated — starts on login, monitors all services, auto-restarts on failure

Scheduler (index.js)

Yahoo svc :5300
The scheduler is managed by a macOS LaunchAgent (com.newleaf.pipeline) with KeepAlive: true. On boot it auto-starts server.cjs and Yahoo OI service. If any service dies, the 5-minute health check restarts it.
Schedule (All Times ET, Mon–Fri)
On Boot Start server.cjs (:3000) + Yahoo svc (:5300) AUTO
*/5 min Health check — restart any down service (server.cjs, Yahoo svc) AUTO
*/15 min Fast pipeline — Alpaca prices + IV for 111 symbols (market hours only) INTRADAY
9:25am Pre-market check — ensure all services up before OI enrichment AUTO

6:00pm Update pick outcomes (crontab) CRON

Open Interest (fallback)
Per-expiry fallback: if Nasdaq returns empty OI for a specific expiry, Yahoo svc is tried. If Nasdaq expiries themselves fail, all expiries come from Yahoo. meta.dataSource.openInterest tracks which source was used: nasdaq-api, yahoo-svc, or none.
