⚙️ AI Adjust
SHIPPED Premium $149 NewLeaf-Max Phase 3
Where
Invest → StrategyDetailPage → AdjustTab (manage mode)
src/trading/pages/StrategyDetailPage.jsx
API Endpoint
POST /api/adjust
// Request { "ticker": "AAPL", "legs": [{ type, strike, expiry, side, qty }], "pnl": { current, maxProfit, maxLoss }, "greeks": { delta, gamma, theta, vega }, "dte": 14, "verdict": { word, confidence }, "chain": { /* nearby strikes + greeks */ } } // Response { "adjustments": [ { "type": "roll_down", "newLegs": [{ type, strike, expiry, side, qty }], "reasoning": "Rolling short put down to 170 reduces delta...", "riskLevel": "moderate", "netCreditChange": -0.35, "newMaxLoss": -420 } ], "model": "newleaf-max" }
Frontend Files
src/shared/hooks/useAIAdjust.js — new hook
src/trading/components/AIAdjustmentCard.jsx — new component
src/trading/pages/AdjustTab.jsx — modified
Model Tier
NewLeaf-Max (Claude Sonnet + GPT-4o) — requires multi-factor reasoning across greeks, P/L scenarios, chain data, and position context. Too complex for Plus tier.
Fallback
Falls back to existing adjustmentCatalogue.js rule-based adjustments. Button text changes to "Rule-based suggestions" instead of "AI suggestions".
Complexity
High — ~5 days. Requires chain data formatting, multi-model routing, ranked output with risk scoring, and integration with existing manage mode UI.

Medium — ~2 days. Straightforward request/response. Main work is integrating tooltips and expanded explanations into existing verdict UI.

Complexity
Low-Medium — ~1.5 days. Existing chat API reuse. Main work is serializing variant data from the builder and rendering ranked results.

Implementation Timeline

3 phases over 5 weeks — shipping value at each milestone

P1
Phase 1 — Foundation
Week 1 • Low-complexity, high-leverage features
F5 AI Chat Enhancement
F6 Interactive Strategy Tutor
F8 Workbench Variant Ranking
Goal: Ship 3 features using existing API infrastructure. Establishes AI presence across Invest, Learn, and Workbench. No new API endpoints required — all use existing /api/chat or aiChat Cloud Function.
P2
Phase 2 — Core Intelligence
Week 2–3 • New API endpoints + model routing
F2 Live AI Verdicts
F3 Weekly Picks Narrative
F7 Earnings/Dividend Risk
F4 Strike Comparison Cards
Goal: Build out 4 new API endpoints. Implement LLM Router for model selection (Plus vs Max). Add event risk data source (earnings calendar). Verdict explanations and narrative bring AI to the daily user experience.
P3
Phase 3 — Advanced AI
Week 4–5 • High-complexity, Premium-tier flagship
F1 AI Adjust
Goal: Ship the most complex feature — AI-powered position adjustments. Requires full chain data integration, multi-model reasoning (Claude + GPT-4o), ranked output with risk scoring, and seamless integration with existing manage mode UI. Premium-only flagship feature.
