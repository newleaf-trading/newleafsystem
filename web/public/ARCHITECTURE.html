Data Flow: Discovery to Published Pick

1
AI Discover → NewLeaf API User enters ticker. API fetches snapshot, option chain from Alpaca. AI selects strategies.
2
AI Discover → NewLeaf API /verify 4-agent verification: technical, gamma, IV/skew, sentiment engines produce verdict + confidence.
3
AI Discover → Firestore recommendations User clicks "Publish to Picks". Recommendation saved with status: wip (legs, verdict, evidence).
4
process-wip-picks.cjs → Firestore recommendations CLI script queries recommendations where status = 'wip'. Status updated to processing.
5
process-wip-picks.cjs → Alpaca + R2 + LLMs Refreshes live prices/greeks, fetches gamma walls, runs 4-engine sentiment, runs Claude deep analysis.
6
process-wip-picks.cjs → Firestore tiles + analyses + weeklyPicks Publishes enriched tile, full analysis doc, and adds to weekly picks collection.
7
process-wip-picks.cjs → R2 + Email Generates PDF report, uploads to R2. Sends email notifications to subscribers.
8
Picks + Invest ← Firestore Web apps read tiles, analyses, weeklyPicks. Pick is now live for users. Recommendation status: complete.
